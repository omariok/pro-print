# Про-Принт — правила для Claude

Сайт производства пищевых плёнок: Next.js 15, React 19, TypeScript, Tailwind v4, framer-motion, three.js. Устройство проекта — в `README.md`, дизайн-система — в `DESIGN.md`, продукт и аудитория — в `PRODUCT.md`. Весь текст сайта — в `src/lib/content/`: `ru.ts` (основной), `en.ts`, `zh.ts`. Меняя текст, правьте все три языка.

## Общение и процесс

- Отвечать пользователю по-русски, простым языком.
- Коммитить только по просьбе. Если попросили сделать что-то «в отдельной ветке», коммиты в эту ветку подразумеваются — сообщать об этом в отчёте.
- Пушить только по просьбе. Репозиторий `omariok/pro-print` остаётся приватным.
- Любые установки и загрузки (npm-пакеты, ffmpeg, инсталляторы) — только с явного разрешения. `npm install` по существующему `package.json` можно.
- Не присылать файлы, о которых не просили.
- Опасные git-операции: сначала посмотреть, что будет потеряно; вместо `reset --hard` предпочитать `stash`.
- Если пользователь остановил dev-сервер — не перезапускать без просьбы.
- CMS отложена, не предлагать и не внедрять.
- Аккаунты, оплату и пароли пользователь делает сам.

## Тексты и факты (обязательно)

- Не выдумывать факты о продукции и не менять тексты без согласования.
- Про-Принт **не производит плёнку** — никогда не называть компанию изготовителем плёнки.
- Номер ГОСТ не указывать (пользователь уточнит). ТР ТС 005/2011, ТУ и протокол испытаний упоминать можно.
- Толщина — «от 8 мкм». Перфорация — не услуга, не предлагать её как услугу.
- Тексты про ПВХ перефразированы с сайта конкурента — никогда не вставлять оригинал дословно.
- Сохранять в футере строку «Изображения продукции — визуализация, до фотосъёмки производства».
- Телефон: +7 994 412-97-44, ссылка `tel:+79944129744`.

## Дизайн

- Никаких «бровей»: без надписей-кикеров над H1 и заголовками секций.
- Никаких тёмных графитовых секций. Не возвращать токены `surface-ink`, `on-ink*`, `accent-lift`.
- Голубой, пурпурный и жёлтый — только в знаке логотипа и в графике шара (WebGL-лента в Hero тоже считается графикой шара). Единственный акцент интерфейса — оранжевый.
- Шар в Hero: сохранять CMYK/ΔE-цвета, смешивание при наведении и пипетку.
- Анимации сдержанные; при `prefers-reduced-motion` — статичный кадр.

## Ветки

- `main` — единственная ветка. В Hero — шар с прозрачной лентой плёнки (`src/components/graphics/orbFilm.ts`), печать в два ручья.
