# Про-Принт — сайт производства пищевых плёнок

Next.js 15 (App Router) + React 19 + Tailwind CSS v4 + Framer Motion (облегчённый `LazyMotion`), шар в Hero — three.js. Без UI-библиотек: компоненты написаны вручную.

Дизайн-система целиком описана в [`DESIGN.md`](DESIGN.md) — правила цвета, типографики, форм и навигации смотрите там, этот файл только про устройство проекта. Хостинг, домен, почта заявок и что делать при поломках — в [`DEPLOY.md`](DEPLOY.md).

## Запуск

```bash
npm install
npm run dev
```

Сборка: `npm run build`, продакшн-запуск: `npm start`.

```

    globals.css         дизайн-система: токены @theme, .shell, .h-section, анимации, правила для китайского
```

## Фотографии в «Примерах»

Снимки лежат в `public/examples/` (WebP 1536×1024, 110–150 КБ), пути и подписи — в `examples.items` в `src/lib/content/*.ts`. Первый снимок главный: от xl он стоит крупно слева, два других — столбиком справа. Новое фото сжимайте до WebP той же ширины (sharp уже есть в `node_modules` вместе с Next) и держите пропорцию 3:2 — под неё подобрана сетка. Пустой `src` показывает заглушку «Фотография готовится». Заменяя снимок, давайте файлу новое имя: сжатую копию сервер и браузер держат до недели (`images` и `headers()` в `next.config.mjs`). Обработчик картинок принимает только файлы из `/examples` и `/about`, качество 75 и ширины до 1536 px — новую папку с фото добавьте в `images.localPatterns`.

## Форма заявки

`src/components/ui/RequestForm.tsx` — React Hook Form с валидацией (имя, компания, телефон, e-mail, согласие 152-ФЗ) отправляет заявку на `POST /api/request`. Необязательные поля (объём, машина, макет, комментарий) свёрнуты под «Добавить подробности». Сервер повторяет проверку, отсекает ботов (скрытое поле и заявку быстрее 3 секунд с открытия формы — им отвечает «успешно», ничего не отправляя), пускает не больше 5 заявок с одного IP за 10 минут и 100 в час на весь сайт и шлёт письмо на почту компании. Принимается только JSON с того же сайта, до 32 КБ. В письмо попадают заполненные поля, а в конце — время, IP и редакция документов: это подтверждение согласия на обработку данных. Если человек нажал «Отправить» быстрее 3 секунд (автозаполнение), форма сама придерживает отправку до порога.

Если письмо не ушло, форма показывает ошибку с телефоном. В `npm run dev` без настроек SMTP заявка просто печатается в консоль сервера.

## Палитра

Кремовая бумага `#fdf6e3`, графитовый текст `#233038`, единственный акцент — оранжевый `#ff5b04` (для текста — `#b53c00`). Голубой, пурпурный и жёлтый живут только в знаке логотипа и в графике шара. Токены — в `@theme` в `globals.css`, расшифровка — в `DESIGN.md`.

## Адаптив и анимации

Брейкпоинты Tailwind + собственный `xs` (26rem). Появление блоков — компонент `Reveal` (общий IntersectionObserver, один раз); если скрипты не запустились, контент всё равно показывается через `<noscript>` и 4-секундный запасной таймер. Декоративные анимации отключаются при `prefers-reduced-motion`.

## Сервер

Сайт работает на Timeweb Cloud App Platform: сборку, запуск, HTTPS и домен настраивает платформа, подробности и порядок действий при сбоях — в [`DEPLOY.md`](DEPLOY.md). Node.js 22. Локально production-сборку можно поднять так:

```bash
npm ci
npm run build
npm start
```

Переменные окружения для почты (без них в продакшне форма отвечает ошибкой `not_configured`):

| Переменная | Что это | По умолчанию |
| --- | --- | --- |
| `SMTP_USER` | ящик, от имени которого уходит письмо | — |
| `SMTP_PASS` | пароль приложения Яндекса для этого ящика | — |
| `SMTP_HOST` | SMTP-сервер | `smtp.yandex.ru` |
| `SMTP_PORT` | порт (TLS) | `465` |
| `MAIL_TO` | куда слать заявки | почта из `contact-info.ts` |

Перед приложением стоит прокси Caddy платформы: адрес посетителя берётся из последнего элемента `X-Forwarded-For`, который дописывает сам Caddy. Заголовки безопасности (HSTS, CSP, X-Frame-Options) и кеширование файлов из `public/` заданы в `next.config.mjs`, заслон от сканеров и переадресация с `www` — в `src/middleware.ts`. Приложение запускается в одном экземпляре: счётчики заявок хранятся в памяти процесса. Адрес сайта для canonical, sitemap и карточек ссылок — `siteUrl` в `src/lib/i18n.ts`.
